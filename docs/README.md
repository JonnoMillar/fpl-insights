# docs

- `screenshots/` - the images used in the main README.
- `superpowers/` - design specs and implementation plans written before the
  larger features were built (the chip planner, the Scout tab, a code-quality
  audit). They are kept as a record of how those features were scoped and the
  trade-offs considered, not as current documentation: the code and the main
  README are authoritative where they differ.
